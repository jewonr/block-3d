# 블록 3D

블록을 조립해 three.js 3D 장면을 만드는 코딩 학습 사이트.

**바로 열기:** https://jewonr.github.io/block-3d/

## 기능

- 장면 · 도형 · 움직임 · 조명 · 애니메이션 · 이벤트 블록으로 3D 장면 조립
- 블록이 만든 three.js 코드를 바로 실행하고 함께 표시
- 클릭 · 키보드 이벤트, 예제, 저장 · 열기, 단독 HTML 내보내기

## 파일

| 파일 | 내용 |
| --- | --- |
| `index.html` | 화면 구조 |
| `style.css` | 디자인 |
| `blocks.js` | 블록 정의 · 코드 변환 · 예제 |
| `app.js` | 작업 공간 · 3D 실행 · 내보내기 |

폰트: SUIT(본문), JetBrains Mono + D2Coding(코드)
